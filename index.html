Comment ça marche

1. Importer un planning — Touche l'icône ⇪ en haut et choisis un fichier .json contenant ton programme de la semaine. Un exemple rempli t'a été fourni à côté de cette appli : édite-le avec les infos de ta salle.

2. Format du fichier — un objet avec une liste semaines (une par semaine de progression). Chaque semaine a un nom et une liste jours. Chaque jour a un jour, un nom de séance, et soit "repos": true, soit une liste exercices.

{
  "nom": "Mon programme",
  "semaines": [
    {
      "nom": "Semaine 1",
      "jours": [
        {
          "jour": "Lundi",
          "nom": "Push",
          "exercices": [
            {
              "nom": "Développé couché",
              "videoId": "feWp7jZopI8",
              "series": 4,
              "repetitions": 10,
              "poids": 40,
              "repos": 90
            }
          ]
        },
        { "jour": "Mardi", "repos": true }
      ]
    },
    {
      "nom": "Semaine 2",
      "jours": [ ... ]
    }
  ]
}

La semaine 1 démarre automatiquement à la semaine en cours (dates réelles affichées en haut), et l'appli avance toute seule à la semaine suivante chaque lundi. Les flèches ‹ › permettent de consulter les autres semaines à tout moment. (Un fichier avec un seul "semaine": [...] à la racine, sans semaines multiples, reste aussi accepté.)

videoId est l'identifiant YouTube (dans l'URL après watch?v=). Si tu ne l'as pas, mets plutôt un champ recherche avec le nom de l'exercice : l'appli proposera un lien de recherche YouTube. repos dans un exercice est la pause en secondes entre les séries.

3. Pendant une séance — ouvre un exercice, règle poids/répétitions puis touche "Série terminée" : ça enregistre la série et lance automatiquement le repos avant la suivante. Le bouton ⏱ en bas à droite ouvre un chronomètre libre à tout moment.

4. Historique — le bouton 📊 en haut affiche toutes tes séances enregistrées, exercice par exercice, avec le poids et les répétitions de chaque série. Depuis cet écran, "Exporter (.csv)" télécharge un fichier avec tout ton historique (modifiable dans un tableur), et "Importer (.csv)" le réinjecte dans l'appli : les séances déjà connues sont mises à jour et les nouvelles sont ajoutées, rien n'est jamais perdu. Pratique pour sauvegarder tes données ou les transférer sur un autre appareil.

Vidéos — touche la miniature pour ouvrir la vidéo dans YouTube (elle s'ouvre dans l'appli ou le navigateur, plus fiable que la lecture intégrée qui est parfois bloquée par certaines chaînes).
